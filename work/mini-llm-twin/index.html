03 · MongoDB Atlas Vector Search

Stage Payload Trace

System design

mini-llm-twin ingests personal documents and notes, splits them into overlap-preserving chunks, generates embeddings via Google Gemini (`text-embedding-004`), and indexes them in MongoDB Atlas for semantic cosine similarity search.

A containerized FastAPI backend serves structured Q&A responses grounded strictly in retrieved context passages, making the entire service reproducible across environments via Docker.
