The problem

Autonomous agents can diagnose operational signals quickly, but letting an LLM execute state-changing tools without deterministic checks creates silent failure modes: malformed arguments, unbounded retry loops, and unreviewed external writes.

What I built

I built a Python harness exposed through both a CLI and an HTTP API. Every tool call passes typed input/output validation, respects strict retry budgets, and pauses before side-effecting calls so a human reviewer approves or rejects the exact proposed action.

Every decision — approved or rejected — is bound to the exact action payload and written to an inspectable audit record.

How I verified it

The proof of concept passes 368 offline tests covering schema enforcement, retry exhaustion, approval binding, and clean rejection with zero side effects. Synthetic data lets anyone run both branches locally from the repository quick start.
